# Pitches

Hand-made pitch art lives here and is tracked in git (the rest of `assets/` is generated by the export and git-ignored).

- One image per pitch (grass pattern, line markings, goals), nearest-filtered, no mipmaps.
- Design size: the pitch fills the 960x540 viewport. Game coordinates are x 0-100 left to right, y 0-100 own goal to opponent goal (see `data/formation_slots.csv`); map them onto the image in code.
- Name files `pitch_<name>.png` (for example `pitch_day.png`, `pitch_night.png`).
