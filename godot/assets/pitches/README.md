# Pitches and stadiums

Generated by the export step `stadiums` from `data/stadiums.csv` (edit the CSV, not the images) and tracked in git so scenes can reference them on a fresh clone.

One folder per stadium (`ST01`, ...): `pitch.png` (flat top-down ground texture, 1872x1280, 16 px/m, mowing + markings + light baked in), `stand.png` (crowd, tiles sideways), `boards.png`, `net.png`, `thumb.png`, `layout.json`.
The stadium is a **3D scene** (`scenes/stadium/stadium.tscn`, `scripts/stadium/stadium.gd`): the pitch is a textured ground plane, stands / boards / goals / flags / floodlights are built from simple 3D parts, and a Camera3D sits behind the near touchline (TV view, real perspective).
Players stay 2D sprites: `Stadium.add_actor(player, pitch_pos)` projects them onto the screen every frame (position, size by distance, depth order).
World: 1 unit = 1 m, X along the pitch (own goal at -52.5), Z across (far touchline at -34), Y up. Pitch coordinates x 0-100 across (0 = far / top), y 0-100 own goal to opponent goal: `world_pos()` / `pitch_pos()`.
