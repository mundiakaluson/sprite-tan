# Pitches and stadiums

Generated by the export step `stadiums` from `data/stadiums.csv` (edit the CSV, not the images) and tracked in git so scenes can reference them on a fresh clone.

One folder per stadium (`ST01`, ...): `backdrop.png` (pitch with markings, boards, stands, crowd, lights; 1600x708), `goal_back.png` + `goal_front.png` (left goal, side view; the right goal is the same flipped), `corner_flag.png`, `thumb.png`, `layout.json`.
View: TV / broadcast side-on. Pitch runs left to right, own goal on the left. Pitch x 0-100 = across (0 = top of screen), y 0-100 = own goal to opponent goal; `Stadium.pitch_to_screen()` converts.
Scale: 12 px per metre along the pitch, depth squashed 2:1. The backdrop is wider than the 960x540 viewport: the Camera in the stadium scene follows the ball along it.
