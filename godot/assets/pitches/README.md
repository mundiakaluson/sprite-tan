# Pitches and stadiums

Generated by the export step `stadiums` from `data/stadiums.csv` (edit the CSV, not the images) and tracked in git so scenes can reference them on a fresh clone.

One folder per stadium (`ST01`, ...): `backdrop.png` (pitch with markings, boards, stands, crowd, lights; 1252x1075), `goal_far.png`, `goal_near.png`, `corner_flag.png`, `thumb.png`, `layout.json`.
Pitch is vertical on screen, own goal at the bottom. Game coordinates x 0-100 left to right, y 0-100 own goal to opponent goal; `Stadium.pitch_to_screen()` converts. The scene is `scenes/stadium/stadium.tscn` (set `stadium_id`).
Scale: 14 px per metre across the pitch, depth squashed 2:1. The backdrop is bigger than the 960x540 viewport: the match camera scrolls and zooms over it.
